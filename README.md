# Vardan Gupta — Frontend Portfolio

A responsive, buildless portfolio with light and dark themes, local fonts, original project imagery, expandable project details, mobile navigation, a resume download, and email copying where supported. HTML, CSS, and JavaScript run directly in the browser.

The theme follows the device preference on the first visit. The header toggle saves an explicit choice in browser storage when available. Theme initialization runs before the stylesheet to avoid a light flash when opening in dark mode.

## Preview

Open `index.html` in a browser. Fonts, styles, scripts, the project screenshot, and the resume are included. For a local HTTP preview, serve this folder with an existing static server.

## Deploy on Vercel

1. Upload these files to your repository.
2. Import the repository into Vercel and select the **Other** framework preset.
3. Set the Root Directory to `vardan-portfolio` if that folder is inside a larger repository.
4. Leave the Build Command blank and serve the project root as the Output Directory.
