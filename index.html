IIT-H Complaints Website

A shared place for students to raise campus issues, follow their status, and mark them resolved. Built as a group project with Google sign-in, Firestore, and automated email routing.

  • Next.js
  • React
  • Tailwind CSS
  • Firebase
My contribution
Platform development, Google sign-in, complaint storage, and notification automation.
Frontend focus
Authenticated routes, complaint forms, issue lists, and action feedback.
Inside the project

The interface takes an IITH user from Google sign-in to a structured complaint form with hostel, room, issue category, and description. “My Issues” reads complaint records from Firestore and lets users mark issues resolved.

React Context shares authentication state, while React hooks manage forms and data loading. Google Apps Script handles routing and email updates. The pilot deployment reached 500+ active users and supported 200+ monthly logins.

Inside the project

The React interface supports creating and updating credential entries, deleting saved entries, toggling password visibility, and copying values to the clipboard. Tailwind CSS handles the responsive layout, with react-toastify for action feedback.

This is a browser-storage learning project. Entries are stored in localStorage and should be treated as demonstration data.
